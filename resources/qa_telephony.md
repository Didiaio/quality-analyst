# TELEPHONY QUALITY ASSESSMENTS

## Data Overview

- Consultant Name
- TelephonyDigital All '[Team Leader]'
- Monitor Type
- Call/Digital ID
- Assessment Outcome

## Data Pivot

- Category
- Count of Call/Digital ID

## Time Framework

### Audits (6 Per Agent)

- [2] Retentions Audit per agent
- [2] Amendments Audit per agent
- [2] Overall Audit per agent

### Data Quality Checks

- Vulnerability Checks (VC)
- Complaints Checks

### Reporting

- Weekly Reporting for Month to date (MTD)
- Update VC Report with Template Calculator

## Targets

- 100% VC checks - Health
- 30% VC Checks - Finance
- 3 Audits per agent for the month

## Formula

```TXT
Quality Score = +- 100%

Formula = (score/total) * 100
        = Average Score for the month (Range)
```

## Coaching Feedback

- Provide feedback to agents based on the evaluation of customer interactions, highlighting areas of improvement and recognizing exceptional performance.
- Collaborate with the training team to identify training needs and develop training materials to enhance agent performance.
